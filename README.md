# AgentWeather: Agentic Multi-Metric Weather & AQI Forecasting
10Pearls SHINE Internship, Cohort 10 (2026)

Forecasts AQI, temperature, precipitation (+ rain probability), humidity, UV index and wind
(speed + direction) 24 hours ahead for Karachi, with a LangGraph agent layer (Forecast, Alert,
Weather Report, Drift), automated by GitHub Actions and shown on a Streamlit dashboard.
